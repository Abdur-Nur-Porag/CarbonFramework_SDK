# Divider

Divider is a simple UI component used to separate content with lines and optional text.

## Use Example
```jsx
<DividerBody type="dash">
  <DividerText>OR</DividerText>
</DividerBody>

<DividerBody type="dot">
</DividerBody>
```

## Attribute Define:
### DividerBody
1.  **type** = Style of the line ("dash" or "dot"). Default is a solid line.

### DividerText
The content inside this tag will be displayed in the middle of the divider line.
